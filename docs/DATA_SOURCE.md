# 데이터 출처와 해석

확인일: 2026-10-24. 아래 설명은 공식 페이지, 로컬 파일 실측, 해석·제안을 구분한다.

## 출처·보관

- 출처: [Olist Brazilian E-Commerce Public Dataset](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce).
- 제공자: Kaggle의 Olist 배포 페이지. 브라우저에서 Version 2, CSV 9개, 라이선스 [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/) 표시를 확인했다.
- 사용자가 다운로드·압축 해제한 로컬 파일은 `data/raw/archive/`에 있다.
- 배포 페이지의 표시 버전과 로컬 파일이 동일한 배포본인지 공식 체크섬으로 대조한 것은 아니다. 이번 입력은 [실측 보고서](DATA_PROFILE.md)의 SHA-256으로 식별한다.
- 원본은 수정하지 않았다. 적재 시작 전과 완료 직전 파일 지문을 비교했다.
- DB: `data/processed/insightagent.duckdb`. 원본·DB·기계 판독용 JSON은 로컬 보관한다.
- GitHub에는 코드·문서·집계 보고서·합성 테스트만 게시한다. 데이터 라이선스를 자체 코드의 라이선스로 간주하지 않는다.

## 적재 정책

- 원본 행 보존: 중복 제거, 결측 보정, 취소·미배송 행 삭제를 하지 않는다.
- 식별자·우편번호: VARCHAR로 보존해 앞자리 0을 유지한다.
- 금액: DECIMAL(18,2). 소수 2자리 초과 등 손실이 생기는 입력은 오류로 중단한다.
- 정수·날짜: 변환 실패와 정수의 소수부 손실을 검사한다. 빈 필드는 NULL로 보존한다.
- 날짜: 원본의 시간대 없는 TIMESTAMP로 적재한다. UTC·브라질 현지 시각으로 임의 변환하지 않는다.
- 컬럼명: 원본의 `product_name_lenght` 등 철자도 그대로 보존한다.
- 키 후보: 실제 고유성은 측정하지만 원본 테이블에 PK·FK 제약을 강제해 데이터를 누락시키지 않는다.
- `_source_files`는 파일명·SHA-256·행 수를 기록한 추가 메타데이터 테이블이다. 데이터 본체는 9개 테이블이다.
- 기존 DB를 덮어쓰지 않는다. 새로 적재하려면 다른 `--output` 경로를 지정한다.

## 주요 실측 결과와 의미

수치는 [DATA_PROFILE.md](DATA_PROFILE.md)와 로컬 JSON에서 재현한다.

- 고객: `customer_id`는 99,441개로 고유하다. `customer_unique_id`는 96,096개이며 반복 고객을 연결하는 식별자다. 두 값을 같은 의미로 세지 않는다.
- 리뷰: `review_id` 단독은 중복되며, 이번 입력에서는 `(review_id, order_id)` 조합이 고유하다. 주문별 리뷰도 여러 행일 수 있다.
- 지리정보: 우편번호 접두사는 여러 좌표에 연결된다. 주문 데이터에 원본 지리정보를 그대로 연결하면 행이 크게 늘 수 있어, 지역 분석 시 집계 단위부터 정해야 한다.
- 주문 99,441행을 상품·결제·리뷰에 순서대로 LEFT JOIN하면 119,143행이 된다. 주문별 사전 집계 없이 금액을 더하면 중복 집계 위험이 있다.
- 주문 상태가 delivered인데 고객 배송일이 NULL인 행이 8개 있다. canceled인데 고객 배송일이 존재하는 행도 있다. 상태와 날짜를 함께 검토해야 한다.
- 상품 카테고리 번역 연결이 안 되는 상품은 13행이다. 원문 코드 2종은 `pc_gamer`, `portateis_cozinha_e_preparadores_de_alimentos`다. 번역 테이블 INNER JOIN으로 제외하지 않는다.
- 구매 시각 전체 범위는 2016-09-04~2018-10-17이다. delivered 주문의 구매 범위는 2016-09-15~2018-08-29다.
- 범위 안에서도 2016-11 구매 행은 없다. 월별 분포와 조건별 실제 관측 유무를 함께 확인해야 한다.
- `shipping_limit_date` 최댓값은 2020년이다. 이를 2020년 매출 데이터가 있다는 근거로 사용하지 않는다. 자동 보정하지 않고 원본을 보존한다.
- 일부 달은 관측량이 매우 작고 경계 달은 부분 기간일 수 있다. 기간 비교와 추세 해석에 제한을 표시한다.

## 리뷰 텍스트·언어

- 리뷰 99,224행 중 제목 또는 본문이 있는 행은 42,697행이다. 본문이 있는 행은 40,968행이다.
- 로컬에서 짧은 본문 5개를 육안으로 읽어 포르투갈어 텍스트를 확인했다. 전체 텍스트의 언어 분포를 자동 분류한 결과는 아니다.
- 영어 카테고리 번역 파일은 리뷰 번역이 아니다. 리뷰를 영어·한국어로 해석하려면 별도 검증이 필요하다.
- 원문 리뷰·개별 고객 식별자를 이 문서에 복제하거나 외부 LLM에 대량 전송하지 않았다.
- Phase 7에서는 검색·분류의 언어 지원과 근거 리뷰 연결을 검증한다. 텍스트 없는 평점도 존재하므로 텍스트 분석의 모집단과 평점 분석의 모집단을 구분한다.

## 남은 해석 제한

- 반환·환불·회계상 매출 인식을 확정할 자료가 충분한지 별도 확인이 필요하다. 상품금액·결제금액을 같은 지표로 취급하지 않는다.
- CSV 자체에는 통화 코드 컬럼이 없다. KPI 초안에서는 원본 금액 단위를 유지하고 환산하지 않는다. BRL 표기는 추가 출처 확인 후 확정한다.
- 이 보고서는 데이터 품질과 관계 조사이며 지표 정의 승인이나 인과관계 검증을 대체하지 않는다.
