## 목표와 MVP

실제 Olist 데이터를 바탕으로 질문 → SQL → 안전성 검사 → 조회 → 시각화 → 근거 있는 설명을 연결한다. 사용자가 데이터 흐름과 계산·검증의 이유를 설명할 수 있도록 단계별로 협업한다.

MVP는 Phase 6까지의 로컬 단일 사용자 서비스다. 월별 매출·주문수, 카테고리 매출 순위, 배송 지연, 지연과 평점 관계를 우선 지원한다. 재구매율은 정의를 조사하되 MVP 구현 필수 항목에서는 제외한다.

리뷰 불만 분석은 Phase 7, 종합 평가와 포트폴리오 정리는 Phase 8에서 수행한다. 로그인·다중 사용자·클라우드 배포·임베딩 인프라는 첫 MVP에 포함하지 않는다.

## 예정 내부 구조와 계약

아래는 자체 구현 제안이며 파일·함수 API는 해당 Phase 승인 시 확정한다.

| 구성 요소 | 입력 | 출력·책임 |
| --- | --- | --- |
| 데이터 구축 | 사용자가 확보한 원본 CSV | 로컬 DuckDB, 타입·키·기간·품질 보고 |
| 분석 메타데이터 | 데이터 조사 결과, 승인 KPI, 기준 SQL | 모델에 전달할 제한된 분석 문맥 |

| 에이전트 | 사용자 질문 | 상태·호출 횟수·한도·결과·종료 이유 관리 |

지표나 기간이 모호하면 확인을 요청하고, 데이터가 없으면 실제 범위를 알린다. 초기 호출 한도는 LLM 3회, SQL 수정 1회·실행 2회다. API 인증·한도 오류와 위험 SQL은 즉시 종료한다. 구현과 차단 테스트는 Phase 5에서 수행한다.

- 9개 테이블 적재, 원본 지문 유지, 변환 손실 없이 행 수 일치.

- 실 연결 시험 예산: 고정 영어 문장 1회, 출력 최대 64토큰, 자동 재호출 0회. 원본·리뷰·집계 전송 없음.

- 호스팅 모델이 현재 키와 요청 파라미터를 수용함을 확인했다. 한국어 SQL 생성 정확도·안전성·계정 잔여 한도는 이번 연결 시험으로 검증하지 않았다.
- 세부 설정·명령·공식 출처는 [NVIDIA_API](NVIDIA_API.md)를 참조한다. Phase 5는 아직 승인·구현하지 않았다.
